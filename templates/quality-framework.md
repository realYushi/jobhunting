# Master Quality Framework

## Phase 0: Truthfulness Validation ✅/❌ (CRITICAL FIRST)

### Factual Accuracy Check (MUST ALL PASS)
- [ ] **Experience Claims**: All projects/roles verified against `base-resume.json`.
- [ ] **Achievement Metrics**: All percentages/numbers match actual, verifiable accomplishments.
- [ ] **Skills Listed**: All technologies mentioned exist in the candidate's actual skill set.
- [ ] **Education Details**: GPA, institution, and dates match official records exactly.
- [ ] **Certifications**: All mentioned certifications are verifiably held by the candidate.
- [ ] **No Fabrication**: Zero fictional projects, roles, or achievements are present.

**Truthfulness Score**: ✅ VERIFIED / ❌ FALSE CLAIMS FOUND
**If FALSE CLAIMS FOUND**: IMMEDIATE RESTART with a truthful foundation is required.

## Phase 3: Word Usage Validation

### Overused Word & Phrase Check (Fewer is better)

**Instructions**: Scrutinize the document for the following words and phrases. They are often unnecessary and can be replaced with more direct and impactful language. Use them only when they are genuinely the best and most precise choice for the context.

#### Vague Descriptors & Buzzwords
- [ ] **"Robust"**: Avoid. Consider "strong", "reliable", "thorough", "comprehensive".
- [ ] **"Cutting-edge"**: Avoid. Be specific about the technology.
- [ ] **"Dynamic"**: Avoid. Show, don't tell. How is it dynamic?
- [ ] **"Game-changer"**: Avoid. Explain the impact instead.
- [ ] **"Revolutionize"**: Avoid. Too strong. "Significantly improve" or "transform" is better.
- [ ] **"Seamless"**: Avoid. Is it truly without any friction?
- [ ] **"Synergy"**: Avoid. Corporate jargon. Describe the collaboration.

#### Overused Action Verbs
- [ ] **"Delve"**: Avoid. Consider "explore", "examine", "analyze", "discuss".
- [ ] **"Leverage"**: Avoid. Consider "use", "benefit from", "apply".
- [ ] **"Harness"**: Avoid. Consider "use", "employ", "draw upon".
- [ ] **"Navigate"**: Avoid for abstract concepts. Consider "handle", "manage", "work through".
- [ ] **"Showcase"**: Use sparingly. Consider "demonstrate", "highlight", "present".
- [ ] **"Elevate"**: Avoid. How is it elevated? Be specific.
- [ ] **"Foster"**: Use sparingly. Consider "encourage", "promote", "build".
- [ ] **"Unlock" / "Unveil"**: Avoid. Too dramatic. Consider "discover", "reveal", "introduce".

#### Intensifiers & Adjectives
- [ ] **"Meticulously"**: Use sparingly. Was the action truly meticulous?
- [ ] **"Crucial" / "Essential" / "Vital"**: Use sparingly. Does it need to be stated?
- [ ] **"Unwavering"**: Use sparingly. Is the commitment truly unwavering?
- [ ] **"Passionate" / "Excited"**: Use sparingly and with authenticity. Show it, don't just say it.
- [ ] **"Keen"**: Consider "strong", "sharp", "astute".

#### Abstract Nouns & Concepts
- [ ] **"Tapestry"**: Avoid. Consider "collection", "combination", "variety", "mix".
- [ ] **"Landscape"**: Avoid for abstract concepts. Consider "environment", "field", "area", "sector".
- [ ] **"Realm"**: Avoid. Consider "field", "area", "domain".
- [ ] **"Testament"**: Avoid. Show, don't tell. Let the results speak for themselves.
- [ ] **"Pillar"**: Avoid. Consider "foundation", "core component", "key part".

#### Common Filler & Introductory Phrases
- [ ] **"It's important to note"**: Avoid. Get straight to the point.
- [ ] **"It is worth noting that"**: Avoid.
- [ ] **"In today's digital age"**: Avoid. Cliché.
- [ ] **"As an AI Language Model"**: Never use.
 - [ ] **"I hope this email finds you well"**: Use only in actual emails, not cover letters.
