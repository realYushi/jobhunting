# Full Stack Developer - Fonterra IT

## About Fonterra
Fonterra is a New Zealand dairy co-operative owned by NZ dairy farmers. Fonterra IT transforms technology to support the Co-op's purpose, delivering improved operational efficiency and collaboration. Close partnerships with Microsoft and leading software vendors.

## About the Opportunity
As a Full Stack Developer, work alongside AI and Data Science teams, building end-to-end applications that bring Proofs of Concept and AI/Machine Learning ideas to life across operations. Hands-on role for someone who enjoys turning emerging technologies into practical, scalable solutions while applying strong engineering standards and a quality-first mindset.

Influence architecture and design decisions, shaping how innovative solutions are built and adopted. Partnerships with Microsoft and other leading software vendors open the door to learning, collaboration, and networking.

## About You
- Experienced full stack developer with strong background building modern web applications
- Python on the backend
- React or JavaScript on the frontend
- Solid backend engineering: REST APIs, authentication, database connectivity, performance optimisation, clean well-structured code
- Responsive UI design
- Prominent frontend framework such as React or Vue
- State management, asynchronous API calls, authentication, single page application
- Good working understanding of cloud services (i.e. Azure): compute, databases, data storage, secret stores
- Plan and structure application builds
- Collaborate, manage dependencies, contribute to shared outcomes in lean methodology
- Comfortable speaking up with new ideas, challenging conventions
- Actively seek and respond to feedback

Location: NZ (hybrid). Note: encourages applications even from candidates who don't meet every requirement.
