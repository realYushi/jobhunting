# Mobile Developer @ Pathfinder Recruitment

Source: https://au.seek.com/job/92085636?type=standard&ref=search-standalone&origin=cardTitle#sol=31b6e3b372a993a3ef9b686e211b2b28e815e7d2

Growing digital agency with it's head office in Sydney is looking for a Senior Mobile Developer to join the team in a remote capacity. You will need to be based in Australia to be considered.The Mobile Developer will be responsible for the delivery of outstanding mobile applications, working from a defined solution architecture and scope. This role will require someone to be a highly experienced , switched on developer who can think on their feet.In this role you will be responsible for:Execute the build of the mobile app to the scope and architecture defined by the team, raising concerns or counter-proposals where architecture and implementation reality don't quite line upWrite clean, well-structured, well-tested code in the chosen mobile framework (currently expected to be React Native with TypeScript)Implement integrations with biometric auth, enterprise SSO, payment and wallet flows, loyalty points, and booking systemsEstimate your own work accurately and flag scope or timeline risks before they become problemsParticipate in client meetings and support technical discussions when neededWrite clear technical documentation as you buildTake ownership of the app release process across iOS App Store and Google PlayContribute to the triage and response to production issues on the app once it's liveTechnologies needed to be considered include:Strong hands-on experience building production React Native apps with TypeScriptComfortable with the React Native ecosystem including Expo or bare workflowExperience with navigation libraries (React Navigation), state management(Redux Toolkit, Zustand, Jotai, or similar), and modern data fetching patterns (React Query / TanStack Query)Experience integrating mobile apps with biometric authentication, OAuth 2.0 / OIDC identity providers, payment SDKs or wallet flows, and REST or GraphQL APIs in generalExperience writing unit tests, component tests, and integration tests for React Native (Jest, React Native Testing Library)End-to-end experience publishing apps to the iOS App Store and Google Play StoreExpert knowledge of Git, including branching strategies, meaningful commit messages, and pull request review workflowsOpen to learning and integrating AI-assisted development tools into your workflow
