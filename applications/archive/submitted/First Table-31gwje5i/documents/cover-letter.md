# Cover Letter — First Table

**Date:** 2026-06-05
**Position:** Growth Engineer

Hi Hiring Team, <!-- replace with named contact if known -->

First Table stood out because the role is explicitly about experimentation: using web and mobile changes to improve how diners discover, book, and return. I like that the work is tied to conversion, onboarding, and evidence rather than shipping for its own sake. The mix of Next.js, React Native/Expo, React, and TypeScript also matches the kind of cross-surface product work I enjoy.

In my current role at GrowLab Technologies, I build internal tools and client-facing applications with React, TypeScript, Node.js, and .NET, and I take features from prototype to production-ready release. A recent example is a customer-facing RAG chatbot I shipped as a separate Next.js app on Vercel with semantic search and embeddings over product docs; I also rebuilt a marketing site with Astro and Tailwind CSS while keeping the chatbot widget lazy-loaded so it had no impact on the initial page load. Earlier at HALO Systems by Tag IT, I built a real-time HMI dashboard with Vue.js, TypeScript, and Mapbox, added GeoJSON-based live sensor visualisation, and delivered an SVG component library that stayed in use across multiple client sites.

That background gives me a practical mix of shipped web products, reusable frontend work, and production-minded delivery that maps well to a growth role. I would bring an ownership mindset to experiments, funnel improvements, and cross-functional iteration, while staying focused on what the data says is changing customer behaviour. I’m based in Auckland and would welcome the chance to contribute to a team that cares about speed, learning, and measurable outcomes.

Sincerely,
Yushi Cui
