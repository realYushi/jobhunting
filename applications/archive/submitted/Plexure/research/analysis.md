## 1. Role Overview

- **Position Level**: Intermediate, with one role possibly Intermediate/Senior
- **Department**: Backend Engineering / SaaS Platform

- **Work Focus**: Backend solutions, platform reliability, CI/CD, automated testing, identity/auth, integrations, and AI-enabled engineering workflows

1. **Opening Hook**: Plexure’s SaaS platform scale, backend quality work, and Personalized Content & Integrations squad.
2. **Key Selling Points**:
   - C#/.NET/Azure/GitHub Actions/SQL Server project foundation.
   - React/frontend ability for customer portals.
   - AI tooling experience from Decoded and GrowLab.
3. **Address Concerns**: Acknowledge no deep production identity/OAuth/Bicep experience; position as junior-to-intermediate growth fit.

1. **Skills Section**: Highlight C#, .NET Core, SQL Server, Azure, GitHub Actions, React, TypeScript, Git, AI Agents.
2. **Experience Section**: Keep GrowLab and Decoded prominent for AI-enabled engineering; include todo app for .NET/Azure proof.
3. **Achievements**: Use 99.9% API uptime and 70% deployment time reduction from the todo app only if supported by base resume.
