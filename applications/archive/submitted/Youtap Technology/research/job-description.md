# Graduate Front-end Software Developer

**Company:** Youtap Technology Ltd
**Location:** Auckland, Auckland, New Zealand (on-site)
**Seniority:** Entry level
**Employment type:** Full-time
**URL:** https://www.linkedin.com/jobs/view/4416974365/

## Description

Youtap Limited, a leading global provider of white-label technology for digital banking, financial institutions, and corporates, is looking for a talented Graduate Software Developer to join their growing team. You will contribute to building innovative web and mobile applications across Youtap's digital payments, digital banking, and loyalty reward platforms — using AI tools to move fast and ship features that matter.

This is an exciting opportunity for a recent graduate who thrives in a fast-paced environment and is passionate about using AI-powered development tools to ship high-quality software quickly. At Youtap, we expect our developers to leverage AI at every stage — from scaffolding features and writing tests to debugging and code review — so you can focus on solving real problems and delivering value fast. You will work closely with product managers and architects to bring compelling experiences to life for consumers and merchants across the fintech and loyalty space.

## Responsibilities

- Build and maintain web and mobile applications using React across Youtap's digital payments, wallet, and loyalty products
- Use AI-assisted development tools (such as GitHub Copilot, Claude, and Cursor) as a core part of your workflow — rapidly prototyping, generating boilerplate, writing tests, and iterating on features at speed
- Collaborate closely with product managers to understand requirements and translate them into responsive, intuitive interfaces
- Work with solution architects to ensure your code meets technical standards, scalability requirements, and best practices
- Translate UI/UX designs into clean, reusable React components
- Integrate with REST APIs and back-end services to deliver seamless end-to-end features, using AI assistance to accelerate integration and reduce time to production
- Participate in code reviews, sprint ceremonies, and continuous improvement practices
- Rapidly build and iterate on new features, using AI tools to reduce development time and get working software in front of users sooner
- Optimise application performance for both web and mobile environments

## Requirements

- A bachelor's degree (or near completion) in Computer Science, Software Engineering, or a related field
- Foundational knowledge of React, JavaScript, HTML, and CSS
- Demonstrated ability to use AI coding tools (e.g. GitHub Copilot, Cursor, Claude, ChatGPT) as an everyday superpower — show us what you've shipped and how fast you shipped it!
- A strong interest in fintech, digital payments, or loyalty/rewards platforms
- Ability to collaborate effectively with cross-functional teams including product, design, and engineering
- A bias for action — you're comfortable shipping iteratively in a fast-paced environment, adapting quickly when priorities shift, and using AI tools to close skill gaps on the fly
- Familiarity with Agile development methodologies is a plus
- Must have the right to work in New Zealand (citizenship, residency, or valid open work visa)
- Must be able to work on-site in Auckland CBD
