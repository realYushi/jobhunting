# Requirements Analysis - Software Engineer (Healthcare Technology)
## Orion Health

### Analysis Overview
Based on Orion Health's technology stack, product portfolio, and healthcare focus, this analysis identifies both explicit technical requirements and implicit healthcare domain expectations for software engineering roles.

## Critical Requirements (Must Have)

### Core Programming Skills
- **Modern Web Development**: React, JavaScript, TypeScript for frontend applications
  - *Evidence*: Company uses React extensively for their healthcare portals and clinical interfaces
  - *Criticality*: Essential for all UI development across their platform suite

- **Backend Development**: Java and/or Scala for enterprise healthcare systems
  - *Evidence*: Java/Scala mentioned as core technologies in their modern tech stack
  - *Criticality*: Required for scalable healthcare backend services and integrations

- **Cloud-First Development**: AWS platform proficiency
  - *Evidence*: Company explicitly states "cloud-first deployment using AWS"
  - *Criticality*: All new development is cloud-native on AWS infrastructure

### Big Data & Streaming
- **Apache Kafka**: Real-time healthcare data streaming and event processing
  - *Evidence*: Listed as core technology for handling healthcare data flows
  - *Criticality*: Essential for real-time patient data processing across systems

- **Apache Spark**: Large-scale healthcare data processing and analytics
  - *Evidence*: Used for population health insights and data science applications
  - *Criticality*: Required for handling healthcare data at scale (150+ million patients)

### Healthcare Standards Knowledge
- **FHIR Interoperability**: Understanding of healthcare data exchange standards
  - *Evidence*: Company is leader in healthcare interoperability with FHIR focus
  - *Criticality*: Fundamental to all healthcare integration work

- **Security & Compliance Mindset**: Healthcare data protection awareness
  - *Evidence*: Multiple certifications (HITRUST, SOC 2, ISO 27001) and patient data handling
  - *Criticality*: Non-negotiable due to sensitive healthcare data handling

## Preferred Requirements (Nice to Have)

### Advanced Technologies
- **Kubernetes**: Container orchestration for healthcare microservices
  - *Evidence*: Listed in their technology stack for scalable deployments
  - *Preference Level*: Highly valued for cloud-native architecture

- **Elasticsearch**: Search and analytics capabilities for healthcare data
  - *Evidence*: Used for search functionality across their platform
  - *Preference Level*: Important for data discovery and analytics features

- **Machine Learning/AI**: Healthcare analytics and predictive modeling
  - *Evidence*: Recent HEALWELL AI acquisition and focus on AI-enhanced healthcare
  - *Preference Level*: Growing importance with AI integration strategy

### Healthcare Domain Experience
- **HL7 Standards**: Healthcare messaging and integration protocols
  - *Evidence*: Healthcare interoperability focus and standards compliance
  - *Preference Level*: Valuable for complex healthcare integrations

- **Healthcare Workflow Understanding**: Clinical processes and EMR systems
  - *Evidence*: Products serve healthcare providers and require workflow integration
  - *Preference Level*: Helpful for building user-centric healthcare applications

- **Population Health Analytics**: Large-scale health data analysis
  - *Evidence*: Orchestral Health Intelligence Platform focuses on population insights
  - *Preference Level*: Important for advanced analytics features

## Implicit Requirements

### Global Collaboration Capabilities
- **Remote Work Proficiency**: Effective in distributed team environments
  - *Evidence*: 17 offices across 11 countries, hybrid work model
  - *Implication*: Must excel in cross-timezone collaboration and communication

- **Cultural Adaptability**: Working with diverse international healthcare systems
  - *Evidence*: Global customer base with different healthcare regulations
  - *Implication*: Understanding that healthcare varies significantly by country

### Mission-Driven Mindset
- **Healthcare Impact Orientation**: Genuine interest in improving patient outcomes
  - *Evidence*: Company mission to "reimagine healthcare experience for all"
  - *Implication*: Technical decisions should consider patient care impact

- **Quality-First Approach**: Understanding that healthcare software requires high reliability
  - *Evidence*: Managing data for 150+ million people across critical healthcare systems
  - *Implication*: Code quality and testing are paramount in healthcare applications

### Continuous Learning Orientation
- **Healthcare Domain Learning**: Willingness to develop healthcare expertise
  - *Evidence*: Complex healthcare domain requiring ongoing education
  - *Implication*: Technical skills must be combined with healthcare knowledge development

- **Regulatory Awareness**: Understanding compliance as feature requirement, not constraint
  - *Evidence*: Multiple certifications and regulated environment
  - *Implication*: Security and compliance are integral to development process

## Experience Level Expectations

### Minimum Viable Experience
- **2-3+ years** software development or equivalent through strong internships + projects
- **Cloud platform** experience (AWS preferred, other cloud platforms transferable)
- **Modern web development** using React or similar component-based frameworks
- **API development** and integration experience
- **Agile methodology** experience with collaborative development

### Preferred Experience Indicators
- **Healthcare or regulated industry** experience (financial services, government)
- **Microservices architecture** development and deployment
- **DevOps practices** including CI/CD pipeline development
- **International team collaboration** or global product development
- **Security-conscious development** with data protection experience

### Advanced/Senior Level Expectations
- **System architecture** design for scalable, compliant applications
- **Technical leadership** in complex integration projects
- **Healthcare standards implementation** (FHIR, HL7, DICOM)
- **Team mentoring** and knowledge sharing capabilities
- **Business requirement translation** from healthcare stakeholders to technical requirements

This requirements analysis indicates a role requiring strong technical fundamentals combined with healthcare domain interest and global collaboration capabilities. The position offers significant growth potential in the expanding digital health sector while contributing to meaningful healthcare transformation.
