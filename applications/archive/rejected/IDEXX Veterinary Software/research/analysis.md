## 4. Application Strategy

### Strategic Keywords

- **High-Priority**: TypeScript, React, APIs, unit testing, CI/CD, cloud-native, modular design, scalable workflows, product engineering.
- **Use Carefully**: Go, AWS, event-driven architecture, containerization, distributed systems. Include only as target role terms or learning areas unless supported by resume evidence.
- **Context Phrases**: "vertical SaaS platform for Animal Health", "practice management", "client engagement", "patient-critical and business-critical activities", "simple yet scalable solutions for complex workflows".

### Cover Letter Focus

1. **Opening Hook**: IDEXX software helps veterinary teams focus on care by connecting practice management, diagnostics, client engagement, and clinical workflows.
2. **Key Selling Points**: Full-stack TypeScript/React work; shipped production-facing client applications; testing/QA and review workflows; practical performance/reliability thinking.
3. **Address Concerns**: Avoid pretending to know Go/AWS deeply. Show transferable backend/API/OOP/cloud deployment experience and appetite to learn in a structured engineering squad.

### Resume Optimization

1. **Skills Section**: Ensure TypeScript, React, Node.js, .NET Core, C#, GitHub Actions, Azure, APIs, Jest/Vitest are visible.
2. **Experience Section**: Emphasize GrowLab and Decoded product engineering; include HALO TypeScript dashboard as relevant domain/workflow evidence.
3. **Projects**: Mini AI App Builder supports testing, React, Node/Express, API integration, production deployment.
