## 4. Application Strategy

### Strategic Keywords
- **High-Priority**: .NET Core, C#, Angular, AWS, Kubernetes, AI tools, ownership, scrum team, SaaS
- **Context Phrases**: "take ownership of features end-to-end", "self-organising, multi-disciplined scrum team", "Airport Smart Technology", "go brilliantly"

### Cover Letter Focus
1. **Opening Hook**: Veovo builds operational software used by major airports, where software quality directly affects real passenger journeys and airport flow.
2. **Key Selling Points**: Direct .NET experience, full-stack delivery across production applications, and practical AI-tool fluency paired with judgment.
3. **Address Concerns**: Be explicit that Angular/AWS/Kubernetes are transferable or ramp-up areas, not claimed deep specialties.

### Resume Optimization
1. **Skills Section**: Keep .NET Core, C#, Angular, AWS, Kubernetes, and AI tooling visible for ATS coverage.
2. **Experience Section**: Lead with GrowLab and Decoded Venture Studio to emphasize ownership, full-stack delivery, and AI-assisted workflows.
3. **Achievements**: Use the .NET Core Todo app and production-facing client work to show shipped software, not just experimentation.

- The JD asks for Angular, AWS, and Kubernetes exposure, but source materials only clearly verify .NET, general frontend depth, Azure, Docker, and GitHub Actions.
- Domain fit is good at the product/operations level, but there is no direct airport or aviation experience, so the application should avoid pretending otherwise.
