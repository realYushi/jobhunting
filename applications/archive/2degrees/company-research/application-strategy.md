# Application Strategy: 2degrees Summer Software Internship

## Strategic Positioning Summary

### Core Value Proposition
Position as a **challenger-minded software engineering student** who embodies 2degrees' "Fighting for Fair" philosophy through innovative thinking, customer-focused development, and genuine passion for using technology to create fairer outcomes for people.

### Key Messaging Themes
1. **Challenger Mentality Alignment**: Demonstrate comfort with questioning conventional approaches and driving innovation
2. **Customer-Led Development**: Show understanding of how software engineering creates direct customer value
3. **Values-Driven Engineering**: Align technical skills with 2degrees' core values of Customer Led, Care, Be Bold, Own It
4. **Growth & Ownership Mindset**: Express enthusiasm for taking ownership of projects and contributing innovative ideas
