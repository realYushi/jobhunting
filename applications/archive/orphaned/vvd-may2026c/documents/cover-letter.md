# Cover Letter — vvd

**Date:** 2026-05-28
**Position:** Design Engineer

Hi Hiring Team,

I'm applying for the Design Engineer role at vvd. Building tools for creators means every interaction needs intention—taste, motion, visual hierarchy, and responsiveness can't be afterthoughts if you want storytellers to actually want to use your product over alternatives.

I build end-to-end with React, TypeScript, and Next.js, and I care about the full experience from interaction design through implementation. At GrowLab Technologies, I rebuilt Truss House's marketing site (a construction-tech company) using Astro and Tailwind with a deliberate, trade-focused aesthetic—clean, uncluttered, with clear information hierarchy. I then shipped a customer-facing RAG chatbot as a separate Next.js app deployed on Vercel, with lazy-loaded semantic embeddings and fast search results. The interface had to feel polished and responsive without getting in the way—zero impact on the marketing site's page load, instant search feedback, clear visual patterns. Earlier, I built HMI dashboards for real-time farm sensor data with Vue.js, TypeScript, and Mapbox visualization, where every pixel and interaction directly affected how farmers understood their operations. I use Claude Code and Cursor routinely to move quickly while keeping the quality bar high—not as shortcuts, but as tools to stay focused on the vision rather than boilerplate. I'm comfortable shipping from rough ideas to polished interfaces without waiting for perfect specs; constraints usually make the work better, not worse.

I'd welcome the opportunity to discuss how I could help you build interfaces that creators genuinely want to use.

Sincerely,
Yushi Cui
